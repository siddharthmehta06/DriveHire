# DriveHire — How to Run the Website

## 1. Start the Project Using Docker (Recommended)

Make sure **Docker Desktop is installed and running** on your system.

Open PowerShell in the project root directory (`DriveHire`) and run:

```powershell
docker compose up -d --build
```

This command builds the required images and starts all services in the background, including:

- PostgreSQL — Database
- MailHog — Email testing service
- Express API — Backend server
- React + Vite — Frontend application

## 2. Seed Sample Data

For the first-time setup, populate the database with sample data by running:

```powershell
docker compose exec -T api npm run db:seed
```

Run this command again whenever you need to reseed the database, if supported by the project's seed script.

## 3. Access the Application

Once the containers are running, open the following URLs in your browser:

| Service | URL |
|---|---|
| **DriveHire Frontend** | [http://localhost:5173](http://localhost:5173) |
| Backend API | [http://localhost:4000](http://localhost:4000) |
| MailHog Email Inbox | [http://localhost:8025](http://localhost:8025) |

Use the frontend URL to access and interact with the DriveHire website.

MailHog can be used to view emails generated by the application during testing.

## 4. View Application Logs

To view logs from all running services:

```powershell
docker compose logs -f
```

To view logs for a specific service:

**Backend API:**
```powershell
docker compose logs -f api
```

**Frontend Client:**
```powershell
docker compose logs -f client
```

Press `Ctrl + C` to stop following the logs. This does not stop the running containers.

## 5. Stop the Project

To stop all services started by Docker Compose, run:

```powershell
docker compose down
```

This stops and removes the project containers and its Compose network. Database data is generally retained if it is stored in a named Docker volume.

To start the project again, run:

```powershell
docker compose up -d
```

## 6. Run Locally Without Docker (Optional)

If you prefer to run the backend and frontend directly on your machine, you can use Docker only for PostgreSQL and MailHog.

### Prerequisites

- Node.js and npm installed
- Docker Desktop installed and running

### Step 1: Start the Database and MailHog

From the project root directory, run:

```powershell
docker compose up -d postgres mailhog
```

### Step 2: Configure and Start the Backend

Open a PowerShell terminal in the project root directory and run:

```powershell
npm run prisma:push
npm run db:seed
npm run dev
```

Keep this terminal running.

### Step 3: Start the Frontend

Open a second PowerShell terminal in the project root directory and run:

```powershell
cd client
npm run dev
```

Keep this terminal running as well.

### Step 4: Open the Website

Visit [http://localhost:5173](http://localhost:5173) in your browser.

**Note:** Ensure the database connection string and other required environment variables are configured correctly in your local environment before starting the backend.

## Troubleshooting

- **Docker connection error:** Start Docker Desktop and wait until the Docker engine is running.
- **Port already in use:** Stop the application using the conflicting port or update the relevant port mapping in `docker-compose.yml`.
- **Frontend or API not responding:** Check the service logs using `docker compose logs -f`.
- **Database connection error:** Ensure the PostgreSQL container is running and the database configuration is correct.
- **Sample data missing:** Run the database seed command again if your seed script supports it.
